# 🏢 GAO Contabilidade - Web

Este é um projeto web moderno desenvolvido para a **GAO Contabilidade**, focado em oferecer uma presença digital profissional, facilitar o contacto de clientes e apresentar serviços contabilísticos de forma clara e eficiente.

## 🚀 Tecnologias Utilizadas

O projeto foi construído com o que há de mais moderno no ecossistema de desenvolvimento web:

* **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
* **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
* **Estilização:** [Tailwind CSS 4](https://tailwindcss.com/)
* **Componentes de UI:** [Radix UI](https://www.radix-ui.com/) e [Shadcn/UI](https://ui.shadcn.com/)
* **Animações:** [Tailwindcss-animate](https://www.npmjs.com/package/tailwindcss-animate)
* **Ícones:** [Lucide React](https://lucide.dev/)
* **Formulários:** [React Hook Form](https://react-hook-form.com/) com validação [Zod](https://zod.dev/)

## ✨ Funcionalidades

* **Design Responsivo:** Adaptado para telemóveis, tablets e computadores.
* **Gestão de Temas:** Suporte para modo claro (light) e escuro (dark) via `next-themes`.
* **Componentes Interativos:** * Carrosséis de imagens (Embla Carousel).
    * Acordéon para FAQs ou detalhes de serviços.
    * Modais e diálogos de alerta.
* **Widget de WhatsApp:** Integração direta para facilitar o contacto imediato de potenciais clientes.
* **Otimização de Performance:** Utilização das últimas funcionalidades do Next.js 15 para carregamento rápido.

## 📦 Estrutura do Projeto

* `/app`: Contém as rotas e a lógica principal da aplicação (Next.js App Router).
* `/components`: Componentes reutilizáveis da interface (Header, Footer, Hero, Serviços, etc.).
* `/components/ui`: Componentes base da interface (botões, inputs, cards) baseados em Radix UI.
* `/public`: Ficheiros estáticos como logótipos e imagens de empresas.
